# 单集分镜格式化（即梦 / Seedance 原稿）

## 输入变量

- `draft_md`：上一步写好的分镜创作稿，是本步唯一的剧情来源。
- `assets`：本集或全集可用的画布资产，包含 `node_id`、`type`、`name`、`look`、`prompt_summary`。
- `max_seconds`：单个片段时长上限，取值4–60。
- `ratio`、`style`：项目画面比例和画风。
- `validation_error`：如有，为上次校验反馈，只用于修正结果。

## 本步职责

把分镜创作稿切成可以独立生成视频的连续片段，并写成即梦 / Seedance 的分栏原稿。本步只重排、切段和补写格式，不增加剧情、动作、台词，也不删减创作稿里的内容。

## 提示词正文

目标平台是即梦 / Seedance。每段 prompt 是提交给它的唯一内容，按下面的分栏顺序写成中文，栏名用【】开头，整段尽量控制在500字内（信息过多模型会丢元素，装不下就拆段）：

1. 【画幅风格】一句话：画幅取输入 `ratio`，画风取 `style`，写出质感与整体色调。
2. 【场景与光】一句话交代空间、时段与固定物；给出全段唯一的光影基准：主光方向、光质（硬/软）、光色冷暖。之后镜头只写光的变化。
3. 【参考与人物】第一次出现的角色、场景、道具各用一次 `@[名称](node_id)`，紧跟用途。之后同一对象仍用同一引用。`node_id` 只能取输入的 `assets`，不编造；没有对应资产就用纯文字描述外貌。
4. 【站位】一行写清每个人：画面左/中/右、依托的固定物、朝向、姿态；多镜同场景写轴线；本段发生的移动写成“起点→终点”。站位是人物方位的唯一来源，镜头里不再重复声明绝对左右。
5. 【时间轴】按先后列出镜头，每镜一行：`起-止秒：景别、角度、运镜。主体动作与神态。声音。台词。` 例如 `0-3秒：中景、平视、缓推。…`。镜头首尾相接，第一镜从0开始，最后一镜的终点正好等于该段 seconds，所有终点不超过 seconds。

对白行格式：台词写成 `角色（语气）：「原文」`，语气放在冒号前；无台词的镜写“台词：无”。对白原文逐字保留，不改写。

切段：创作稿中空行分开的部分可以各自成段，一段的时长不超过 `max_seconds`；放不下就拆成下一段，不在一段里堆叠超出时长的镜头。

收尾：每段最后一镜的句尾写清终点画面（谁在哪、什么姿态、道具状态），供下一段接续；不靠延长静止或重复动作填时长。

## 输出 JSON Schema

只输出一个JSON对象，不带Markdown围栏、注释或解释。所有列出的字段都必须出现，不允许其他字段或null。

```json
{"type":"object","additionalProperties":false,"required":["segments"],"properties":{"segments":{"type":"array","minItems":1,"items":{"type":"object","additionalProperties":false,"required":["seconds","prompt"],"properties":{"seconds":{"type":"integer","minimum":1,"maximum":60},"prompt":{"type":"string","minLength":1}}}}}}
```

## 校验规则

1. segments非空；每段seconds为正整数且≤max_seconds。
2. 每段prompt不能为空，各镜起止秒写在prompt里，首尾相接，合计等于该段seconds，终点不超过seconds。
3. 所有资产引用node_id来自assets；未知引用会降级为纯文字名称。
4. 遵守创作稿的剧情顺序和连续性，不增加未发生的动作或对白，也不遗漏创作稿里的台词。

# 单集剧本创作（写法与创作方法）

## 输入变量

输入来自开头 JSON 数据块：`episode` 为本次要写的一集，包含集号、标题和梗概；`episodes` 可提供全剧分集目录。`outline_md` 为审阅后的大纲，`characters_md` 为人物设定，`source` 或 `summary` 为原文依据，`previous_ending` 是上一集结尾约 800 字，用于衔接动作、对白、时空与悬念。另有 `genre`、`style`、`episode_seconds`、`known_cast`、`hook`、`cliffhanger` 与 `validation_error` 等创作约束。

## 本步职责

本步骤只写本集的剧本创作稿，用自然的中文把场次、动作、对白和结尾写清楚。下一步会把创作稿整理成标准的短剧剧本格式，所以这里不做排版，也不写格式标记。

## 提示词正文

画布上登记的人物名单是实时的，与人物设定冲突时以它为准；沿用正式名字，新称呼归入别名。本集对应的完整原文是改编依据，本集的开场钩子和结尾悬念已由分集规划给出。上一集的结尾如果还没写，按它的梗概与悬念衔接。

你负责一次只完成指定的一集短剧剧本。无论来源是小说、梗概还是已有剧本，输出都必须是可以直接拍摄的剧本，而不是小说缩写或故事复述。围绕本集梗概写出完整的中文剧本，篇幅与给定单集时长相称，明确本集的开场钩子、冲突、发展和结尾钩子。

场次要按地点和时间切分，一场只写一个地点；每场开头交代出场的人物。动作与画面只写镜头能拍到、耳朵能听到的内容：人物的位置、动作、表情外化、道具、环境与声响，用现在时、第三人称。对白使用人物的正式名字，需要时写清语气和同时发生的动作。不在画面里的声音，例如内心独白、电话或画外音，要明确说明它是什么。需要闪回、字幕或空镜时，用能让后续排版准确识别的写法写清楚，不要和正文混在一起。时间跳跃要另起一场，不在一场里跳时间。

全集最后要有一个明确的集尾钩子（反转、揭露、危机或未决选择），与本集规划给出的结尾悬念一致。

写法要求：

- 禁止小说式写法：不写大段心理描写、议论、作者评述，不用「他想起……」「她心中涌起……」这类叙述腔。内心活动只能转成可见的行为、表情外化、道具反应，或一两句简短的内心话。
- 对白要口语化、一句一事：每句台词只推进一件事，允许打断、半句、反问和语气词，避免书面腔长句和解释性对白，不让角色替观众复述剧情。人物之间的称呼要符合身份和关系，前后一致。
- 开场数秒内就要给出钩子或冲突，每场都要有目的与变化，不写不推进剧情的闲笔；节奏紧凑，信息靠动作和对白递出。
- 改编小说时，把章节叙述拆成场次：先确定本集发生了哪些地点与时间，按因果顺序切场；叙述性交代改成动作、对白或字幕，原文中的关键对白尽量保留，但要改写成适合说出口的短句。
- 场景、人物、道具名称与输入名单保持一致，同一地点始终使用同一个名称，方便后续资产拆解与分镜。

首先核对上一集的结尾：延续上一集的人物状态、持有道具、位置与未结束动作；不要把上一集结尾重新演一遍，不无故跳过关键因果。保持人物设定里的正式名字、身份、音色设定和关系一致，依照大纲与本集梗概推进，不提前消耗后续集的核心转折。

输入只覆盖部分作品时，局部细节可以服务于改编表达，但不能推翻已知事件或捏造与原文冲突的人物关系。本步骤只写本集正文，不输出资产清单、分镜节点或其他集。

## 输出约定

只输出本集剧本的纯文本创作稿，按剧情顺序用中文写成。不输出 JSON、代码围栏、开场白或解释。

## 校验规则

- 输出是一段非空的纯文本，只包含本集的剧本内容。
- 本集人物状态与上一集结尾连贯，人物名字与 `characters_md` 一致。
- 不包含 JSON、代码围栏或创作建议。
